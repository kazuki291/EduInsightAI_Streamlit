# EduInsight AI

EduInsight AI is an AI-based Student Academic Performance Prediction System developed using Streamlit and Machine Learning.

## Features

- Student Management
- Academic Performance Prediction (SVM)
- AI-generated Recommendations using Groq API
- PDF Report Generation
- SQLite Database Support
- Dashboard & Prediction History

## Technologies Used

- Python
- Streamlit
- Scikit-learn
- SQLite
- Groq API
- ReportLab
